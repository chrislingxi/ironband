# V3 Amazon Core Slice

目标: 先把一个职业做成可验证的暗黑 ARPG 垂直切片, 不横向铺内容。

## 版本判断

当前问题不是内容少, 而是每次战斗的决策密度低。V3 先押亚马逊, 用远程风筝、控场、穿透和装备变异建立职业幻想。

## 本轮范围

- 职业选择页改为大立绘暗黑卡面: 亚马逊作为推荐职业, 展示“多重箭 / 冰冻箭 / 穿透构筑”。
- 亚马逊起手拥有 3 个主动技能: 多重箭、冰冻箭、魔法箭。
- 起手技能作为职业工具组发放, 不消耗后续升级技能点。
- 血腥旷野加入“猎手试炼”小队: 光环精英督军 + 扑袭兽群 + 远程弓手。
- 首战保底掉落暗金短弓“鸦羽穿心”。
- “鸦羽穿心”改变玩法: 箭矢穿透 + 射程提升 + 多重箭额外 2 发。
- 冰冻箭命中后真正施加控制, 支撑远程风筝。
- “鸦羽穿心”拾取后自动装备, 首战后立即进入穿透箭构筑, 不再卡在背包教学前。

## 后续 V3 仍需补齐

- 单独制作亚马逊 3A 级职业立绘与技能图标 atlas。
- 增加 Boss 技能读条、地面危险区和远程职业位移压力。
- 装备词条扩展为 build modifier 系统, 不再用硬编码暗金特效。
- 为法师/野蛮人各做一个同等标准的职业切片。
