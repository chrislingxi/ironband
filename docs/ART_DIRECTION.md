# Ironband Art Direction

目标：把项目从“AI 生成素材集合”推进到“统一美术导演体系”。3A 感不来自单张图精细，而来自同一套世界观、材质、光照、构图、色彩、动效和 UI 语言长期一致。

## 世界关键词

- 铁：武器、护甲、营地器具、UI 边框都应有冷硬金属磨损。
- 血：战斗反馈、Boss 场、任务完成的仪式感来自深红和暗金，不用廉价高饱和红。
- 营火：营地是唯一温暖安全点，暖橙、烟、布幔、木桩、铁砧都围绕营火展开。
- 腐化：野外、巢穴、Boss 区逐步变冷、变毒、变黏稠。
- 远古遗迹：石碑、断墙、符文、祭坛和被侵蚀的道路提供场景记忆点。

## 视觉层级

1. 战斗主体：玩家、敌人、技能、掉落，最高对比。
2. 当前目标：箭头、目标卡、任务短句、出口/精英提示，中高对比。
3. 常驻 HUD：血量、技能、背包入口，中低对比。
4. 非战斗系统：背包、营地、任务日志，暂停态全屏展示，不抢战斗画面。

## 资产验收

- 缩到游戏内尺寸后，职业和怪物 1 秒内可辨认。
- 透明边缘干净，无发灰、漏白、半透明脏边。
- 武器、手、脸、脚轮廓明确，不接受 AI 常见糊手/糊武器。
- 同屏资产光源方向统一：左上主光，右下压暗。
- 每个怪物有唯一剪影，不只靠颜色区分。
- UI 图标必须能在 48px 内识别，不能依赖复杂细节。
- 技能特效必须有起手、飞行/范围、命中、残留四段之一或多段，不只是一团光。

## 环境优先级

先重环境，再重角色。玩家每秒看到最多的是地面、出口、掉落、技能、HUD 和任务提示。

1. 营地：营火、铁砧、商人摊、符文布、路牌、木栅栏。
2. 血腥旷野：碎石、枯草、尸痕、树根、远处冷雾。
3. 邪恶巢穴：毒池、骨堆、破旗、湿润墙面、低位冷光。
4. Boss 区：专属入口、祭坛、毒雾、压迫性边缘构件。

## 技能语言

- 火：低频爆裂、余烬、橙红核心、暗烟残留。
- 冰：锋利碎片、白蓝高光、短暂冻结裂纹。
- 电：折线、强闪、短尾残影，不做柔软光团。
- 毒：不规则雾、液滴、绿色偏黄的危险边缘。
- 物理：弧线、尘土、火花、击退方向明确。

## 图标系统

图标不能像通用素材库拼贴。技能、装备、任务、营地服务统一为：

- 深色底盘。
- 旧金属外框。
- 单一主体剪影。
- 最多一个高光色。
- 48px 可读，64px 有细节，128px 不空。

## 禁止项

- 随机高亮边和无来源体积光。
- 过甜 Q 版表情。
- 大面积塑料感渐变。
- 同一屏出现多套描边粗细。
- 任务和奖励只靠文字完成。
- 技能图标、装备图标、服务图标来自不同风格库直接混用。
