# Version Upgrade V2 · First Five Minutes

本版本目标：把 Ironband 从“系统已经很多”推进到“新玩家 5 分钟内能玩懂、能拿到装备、能感到变强”的可试玩切片，同时建立后续去 AI 感的美术导演体系。

## 体验升级

- 修复横屏首进背包可能默认显示的问题。
- 取消首次启动的全屏说明书式教程，改为非阻塞目标卡。
- 目标卡按玩家状态动态推进：
  1. 出营地。
  2. 打第一队怪。
  3. 打开背包穿第一件战利品。
  4. 清场后继续推进。
- 目标卡带进度条和“打开背包”行动按钮，不打断战斗。
- 营地也显示出口箭头，避免玩家第一屏不知道往哪里走。
- 血腥旷野首杀保底掉落“营火守望者皮手套”，确保 2 分钟内出现掉装/穿装爽点。
- 首战保底掉落状态写入存档，避免反复刷新刷首件奖励。

## 美术升级

- 新增 `docs/ART_DIRECTION.md`，把素材生产从 prompt 清单升级为 art bible。
- 明确世界关键词、视觉层级、资产验收、环境优先级、技能语言、图标系统和禁止项。
- 后续任务、环境、技能、图标、UI 都按这份标准验收，避免继续堆 AI 拼贴感素材。

## 验收目标

- 30 秒内：玩家知道跟随箭头离开营地。
- 90 秒内：玩家进入第一片野外并完成首战。
- 120 秒内：玩家获得第一件可穿装备。
- 300 秒内：玩家完成“打怪 -> 掉装 -> 穿戴 -> 继续推进”的闭环。

## 暂不包含

- 不新增新幕、新职业或复杂系统。
- 不做动态 Boss scaling。越级返刷低幕 Boss 可以碾压，保留 D2 式返刷爽感。
- 不批量重出 PNG 资产。本版本先建立美术标准和体验框架，下一版再按 art bible 批量换高可见资产。

## V2.1 真机问题修复

- 移动端 viewport 改为 `visualViewport + --app-height` 锁定，连续点击后会重新压回游戏画布，减少 iOS Safari 地址栏导致的画面缩小、错位和横屏截断。
- 背包与符文图鉴 overlay 改为 fixed + 动态高度，横屏时不会被页面滚动状态卡住并拦截游戏。
- 战斗通知从巨型全屏文字改为暗金 toast，普通拾取/药水提示不再遮挡战场，任务完成仍保留庆祝级横幅。
- HUD 技能键重做为暗黑哥特宝石槽：金属边框、内嵌宝石、染金 SVG 图标、底部短标签，替换原本偏 emoji/低保真的观感。
- 亚马逊起手武器改为短弓，默认普攻改为“弓箭射击”，手点与自动普攻都会发射箭矢。

## V2.2 音乐升级

- 新增 CC0 暗黑地牢氛围 BGM：OpenGameArt `Dungeon Ambience`，转为 iOS 兼容的 `public/assets/audio/bgm.mp3`。
- 修复 BGM 采样加载竞态：首次触屏先启动合成底噪时，真 BGM 异步解码完成后会自动切换到采样音乐。
- `ATTRIBUTION.md` 明确登记 BGM 来源、作者、授权和转码方式。
