# V4 Town Service Icons

These editable source renders define the visual language for town services.
Runtime copies are chroma-keyed, resized to 256x256 RGBA PNG, and mirrored in
`assets/icon/` and `public/assets/icon/`.

| Key | Motif | Source key |
| --- | --- | --- |
| `service_forge` | scarred hammer and anvil | magenta |
| `service_shop` | leather purse and old coins | magenta |
| `service_heal` | caged crimson healing vial | magenta |
| `service_identify` | rune scroll and lens | green |

Art direction: premium hand-painted dark fantasy, realistic forged metal,
leather and parchment, readable silhouette at 28px, no text or frame. Sources
were generated with the built-in image generation workflow and locally keyed
to transparency with the imagegen chroma removal helper.
