# V4 Boss Arena Props

`ritual_altar_source.png` was generated with the built-in OpenAI image tool as an original Shattered Crown Altar: blackened iron, cracked basalt, bone inlay, broken crown prongs, and a restrained ember rune basin on a flat green key.

The production asset is chroma-keyed, edge-contracted, despilled, and resized to a 512x512 RGBA PNG. It is shared by the five save-compatible Boss arenas as a visual anchor; arena palette, Boss art, projectiles, and warning colors provide act-specific identity.
